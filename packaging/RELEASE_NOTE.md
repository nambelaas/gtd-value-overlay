## Cara pasang

**Windows**
- Unduh **GTDValue-Setup.exe**, jalankan, lalu buka "GTD Value Overlay" dari Start Menu. Atau unduh **GTDValue-windows.zip**, ekstrak, dan jalankan `GTDValue.exe` (tanpa instalasi).
- Windows mungkin menampilkan peringatan "Windows protected your PC" karena app belum ditandatangani. Klik **More info** lalu **Run anyway**.

**Mac (Apple Silicon)**
- Unduh **GTDValue-mac.dmg**, buka, lalu seret GTDValue ke folder Applications.
- Saat pertama dibuka macOS akan memblokirnya. Klik kanan GTDValue di Applications > **Open** > **Open**. Kalau masih diblokir, jalankan di Terminal: `xattr -dr com.apple.quarantine /Applications/GTDValue.app`.
- Izinkan **Screen Recording** untuk GTDValue di System Settings > Privacy & Security, lalu keluar dari app (ikon V di menu bar) dan buka lagi.

## Cara pakai

Buka Roblox dan masuk ke menu trade Garden Tower Defense. Value muncul di atas tiap unit. Kontrol ada di ikon **V** di tray / menu bar: Jeda, Muat ulang values, Buka folder data, Jalan otomatis saat login, Keluar.

Program ini hanya **membaca layar**. Tidak menyentuh atau memodifikasi client Roblox. Proyek ini tidak berafiliasi dengan developer game.
